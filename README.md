Веб-игра: нужно расставить перемешанные цифры в том же порядке, что и эталонная последовательность сверху. Реализованы два способа перестановки — нативный drag-and-drop и [dnd-kit](https://dndkit.com/).
**Демо:** https://&lt;ваш-username&gt;.github.io/hl-test/

## Возможности
- Эталонная последовательность (компактные карточки) и игровое поле (карточки 200×50 px)
- **Drag and drop** — только по вертикали, с пересчётом порядка остальных карточек
- **Click swap** — первый клик выбирает карточку, второй по другой меняет их местами, повторный клик снимает выбор
- Кнопка **Проверить** — сообщения о победе и ошибке
- После победы перестановки блокируются, доступна **Новая игра**
